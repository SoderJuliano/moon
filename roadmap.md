# Moon — Roadmap (Missões Secundárias e Funcionalidades)

> Brainstorm de ideias. Não é um backlog obrigatório.
> As mecânicas devem aproveitar o máximo possível dos sistemas já existentes
> (planetas, luas, nave, asteroides, scanner, reboque, combate, save, descobertas)
> evitando grandes refatorações.

---

# Filosofia

O modo jogo não deve virar um arcade comum.

A ideia é continuar sendo um "Planetário Jogável".

Toda missão deve ensinar alguma curiosidade científica ou incentivar a exploração.

O jogador sempre deve sentir que está descobrindo algo novo no Sistema Solar.

Sempre que possível:

- utilizar locais reais;
- corpos celestes reais;
- fenômenos reais;
- dados científicos reais.

---

# MISSÃO 01 — Primeiro Contato

Objetivo

Aprender a controlar a nave.

Tarefas

- decolar da órbita terrestre
- visitar a Lua
- voltar para a Terra

Recompensa

- Scanner Básico

---

# MISSÃO 02 — Cientista de Campo

O Scanner passa a ser utilizado.

Visite qualquer planeta.

Ao aproximar:

- composição química
- atmosfera
- temperatura
- massa
- gravidade
- tamanho
- distância ao Sol
- período orbital
- curiosidades

Cada planeta analisado gera:

✔ Descoberta
✔ XP científico
✔ Registro permanente

---

# MISSÃO 03 — Catálogo do Sistema Solar

Objetivo

Escanear todos os planetas.

Depois:

- luas principais
- cinturão principal
- cinturão de Kuiper

Ao completar:

Conquista:

"Cartógrafo do Sistema Solar"

---

# MISSÃO 04 — Asteroides Raros

Alguns asteroides possuem composição especial.

Exemplos

- ferro
- níquel
- ouro
- platina
- gelo
- carbono
- minerais desconhecidos

O scanner identifica.

A garra pode coletar pequenos fragmentos.

Recompensa:

novos upgrades.

---

# MISSÃO 05 — Nave Abandonada

Uma nave antiga aparece perdida.

Ela está sem energia.

O jogador deve:

- localizar
- aproximar
- escanear
- rebocar

Ao levar para uma estação:

recebe peças raras.

Pode haver várias naves diferentes.

Cada uma conta uma pequena história.

---

# MISSÃO 06 — Caixa Preta

Uma nave destruída deixou apenas sua caixa preta.

Localize.

Escaneie.

Recupere.

Ao ler:

pequenos relatos de exploração espacial.

Cada caixa pode contar uma história diferente.

---

# MISSÃO 07 — Campo de Asteroides

Entre Marte e Júpiter.

O jogador deve atravessar um cinturão.

Sem destruir a nave.

Quanto menor o número de impactos:

maior recompensa.

---

# MISSÃO 08 — Corrida Espacial

Missão especial.

Não acontece no Sistema Solar principal.

Carrega uma pequena cena separada.

Objetivo:

corrida entre naves.

Circuito cheio de:

- asteroides
- túneis
- destroços
- curvas

Após terminar:

retorna exatamente para onde estava.

Nada muda na posição do mundo principal.

---

# MISSÃO 09 — Satélites Perdidos

Diversos satélites apresentam falha.

Objetivo:

rebocar até a órbita correta.

Pode ensinar:

- órbitas
- altitude
- gravidade

---

# MISSÃO 10 — Caçador de Piratas

Pequenas naves inimigas aparecem.

Proteja:

- satélites
- estação espacial
- nave científica

Combate simples.

Nada muito arcade.

---

# MISSÃO 11 — Tempestade Solar

Próximo ao Sol.

Uma ejeção de massa coronal ocorre.

Objetivo

Escapar.

ou

Entrar atrás de um planeta para usar sua sombra magnética.

Ensina um fenômeno real.

---

# MISSÃO 12 — Eclipse

Receba uma missão para observar um eclipse.

O jogador precisa posicionar a nave exatamente no local certo.

Ao conseguir:

fotografia científica.

Conquista desbloqueada.

---

# MISSÃO 13 — Chuva de Meteoros

Durante alguns minutos:

pequenos meteoros cruzam o espaço.

Não é um combate.

É um evento.

Pode acontecer aleatoriamente.

---

# MISSÃO 14 — Cometa Visitante

Um cometa entra no Sistema Solar.

Objetivos:

- seguir
- escanear
- fotografar
- analisar composição

Depois ele desaparece.

---

# MISSÃO 15 — Vida?

Ao analisar Europa, Encélado ou Titã.

O scanner detecta:

"Possíveis compostos orgânicos."

Não confirma vida.

Mas cria curiosidade científica.

## Diário Científico

Tudo que o jogador descobrir vai para um diário.

Cada página possui:

- imagem
- nome
- distância
- curiosidades
- composição
- data descoberta
- primeira visita

Funciona como uma Pokédex científica.

---

## Sistema de Pesquisa

Fragmentos coletados liberam pesquisas.

Exemplos:

- motores melhores
- escudo
- canhão de plasma
- scanner
- combustível
- sensores

Nada é comprado.

Tudo é pesquisado.

---

## Sistema de Fotografia

O jogador pode tirar fotos.

Algumas missões pedem imagens específicas.

Exemplos:

- Saturno com seus anéis
- eclipse
- Terra vista da Lua
- Júpiter próximo
- aurora em Júpiter
- cometa

As fotos ficam salvas no diário.

# Ideia Geral

O jogador nunca deve sentir que está apenas "indo do ponto A ao B".

Quase toda viagem deve ter a chance de encontrar algo:

- um evento;
- um objeto científico;
- uma missão;
- um fenômeno astronômico;
- uma nave perdida;
- um pedido de socorro;
- uma corrida;
- um combate;
- um novo registro para o diário.

Assim, mesmo conhecendo o Sistema Solar, sempre haverá um motivo para continuar explorando.
 
 Importante observação: ** Isse roadmap foi criado por uuma ia sem acesso ao jogo, por isso deve-se levar em conta o que já existe no game **

## Future Platform Support

O sistema de entrada (src/input/) foi construído sobre a Gamepad API padrão do
navegador, sem nenhuma API específica de plataforma — o mesmo código roda em
Web, Android (WebView/Capacitor) e futuramente Electron/Steam sem duplicação.

- Steam (empacotar via Electron; o suporte a controle já estará pronto)
- Steam Deck (funciona como gamepad "standard" — já mapeado)
- Full Gamepad Support (analógicos no voo + todos os botões — base implementada)
- Controller Remapping (estrutura pronta em InputSettings.js, falta a tela)
- Force Feedback / vibração (fundação pronta: input.rumble(); falta ligar a
  colisões, tiros, explosões e aproximação de planetas)
- Cloud Save
- Steam Achievements
- Steam Workshop (futuro distante)
- Steam Input API (avaliar somente quando existir versão Steam)
